# Privacy Lens, see what your browser can do

Privacy Lens is a local-only, consent-based browser diagnostics dashboard.

## Safety boundaries

- Fingerprint collection starts only after the visitor enables consent and clicks the run button.
- Camera, microphone, clipboard, and screen sharing are separate, user-triggered tests.
- Media streams are previewed visibly and can be stopped at any time.
- No cookies, local storage, passwords, keystrokes, or browsing history are read.
- No data is uploaded. JSON export is an explicit local download.

## Run locally

Open index.html in a browser. Camera, microphone, clipboard, and screen sharing require a secure context such as HTTPS or localhost; the fingerprint-only view works without a server.
